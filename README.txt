# Stock Trader Pro App

A JavaFX application that displays stock price information and enables the user to test stock trading strategies over a given time period.
 - Displays stock price over time graphically
 - Enables selection of specific stocks to simulate
 - Choose time period of 30, 50, or 70 days.
 - Each simulation starts with a starting balance of $10,000
 - Allows user to buy and sell stocks depending on stock prices
 - Compares user results with averaging in to the S&P

Technologies Used:
 - Java
 - JavaFX
 - Alpha Vantage API
